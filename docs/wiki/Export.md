# Export

The toolbar offers three formats. Every export contains the **whole canvas**, whatever the current zoom.

| Format | Best for |
|---|---|
| **PNG** | Wiki pages, chat, tickets |
| **SVG** | Further editing as a vector graphic, for example in draw.io or Inkscape |
| **PDF (A4)** | Printing and documentation folders: one DIN A4 page with title, date and legend |

Notes:

- Switch to **View only** before exporting so the image has no edit controls.
- PNG and SVG use NetBox's current light or dark theme. The PDF is always light.
- The PDF uses portrait or landscape, whichever fits the canvas better. Large canvases are scaled down to fit one
  page. For very large maps, split them into several canvases, for example one per site.
