# Export

The toolbar offers three formats. Every export contains the **whole canvas**, whatever the current zoom.

| Format | Best for |
|---|---|
| **PNG** | Wiki pages, chat, tickets |
| **SVG** | Further editing as a scalable vector graphic, e.g. in draw.io or Inkscape |
| **PDF (A4)** | Printing and documentation folders: landscape DIN A4 with title, date and legend |

Tips:

- Switch to **"Nur Ansicht"** before exporting so the image has no edit handles.
- PNG and SVG use NetBox's current light or dark theme. The PDF is always printed on a white background.
- Large canvases are scaled to fit one A4 page. For huge maps, split them into several canvases, e.g. one per site.
